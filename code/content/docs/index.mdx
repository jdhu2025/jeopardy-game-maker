## What Quizboard Maker does

Quizboard Maker helps teachers, trainers, and group hosts turn a topic into an editable 5 by 5 quiz board. You can review prompts and answers, adjust point values, host the board on a shared screen, and download a reviewed board as a self-contained HTML game.

## Build a board

1. Enter a lesson, training topic, or event idea.
2. Choose the audience and question language.
3. Start the board and inspect each category and square.

The first draft is a starting point. It is your responsibility to correct facts, wording, age suitability, accessibility, and any local requirements before use.

## Review and edit

Open any square to edit its prompt, answer, explanation, or point value. Check for duplicate questions, vague wording, missing context, and answers that need a source or a more specific explanation.

## Host or download

Use host mode when the board is ready for a shared screen. When internet access is uncertain, download the reviewed board as a self-contained HTML game and keep the file with the same care as any other teaching or training material.
