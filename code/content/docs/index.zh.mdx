## Quizboard Maker 是什么

Quizboard Maker 帮助教师、培训师和活动主持人把主题整理成可编辑的 5×5 题板。你可以审核题目和答案、调整分值，在共享屏幕上主持游戏，也可以把审核后的题板下载为自包含 HTML 游戏。

## 制作题板

1. 输入课程、培训或活动主题。
2. 选择受众和题目语言。
3. 创建题板后检查每个分类和格子。

初始题板只是起点。正式使用前，你需要自行检查事实、措辞、年龄适配性、无障碍要求以及所在组织的具体要求。

## 审核和编辑

打开任意格子即可修改题目、答案、解释或分值。重点检查重复题目、表述模糊、缺少背景信息，以及需要来源或更具体解释的答案。

## 主持或下载

题板准备好后，可以使用主持模式在共享屏幕上进行活动。如果网络不稳定，可以把审核后的题板下载为自包含 HTML 游戏，并像管理其他教学或培训资料一样妥善保存。
